# Module 3 — GenAI Support Assistant

## Objective

Build a policy-based support assistant that retrieves relevant information from Zepto policy documents and generates structured responses.

## Workflow

Policy Documents
→ Text Chunking
→ Embeddings
→ ChromaDB
→ Retrieval
→ LangGraph
→ Response Generation
→ FastAPI

## Technologies

- Python
- Sentence Transformers
- ChromaDB
- LangGraph
- Pydantic
- FastAPI
- Docker
